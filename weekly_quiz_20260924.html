Part 2: 簡短問答 (Question-Response)
請仔細聆聽音檔問題，選出最適合的應答：
題目文本："Has the database administrator authorized the permission change yet?"
解析：問句詢問管理員是否已「授權 (authorized)」權限變更，最適當的回答是 (B)「還沒，她仍在審查登入憑證 (credentials)」。(A) 提容量 (capacity)、(C) 提搬遷 (migrate)，皆不符對答邏輯。
Part 2: 簡短問答 (Question-Response)
請仔細聆聽音檔問題，選出最適合的應答：
題目文本："Why do we need to optimize this API query before launch?"
解析：問句詢問「為什麼在上線前需要優化 (optimize) API 查詢」，最適當的回答是 (A)「為了消除尖峰時段的延遲瓶頸 (bottleneck)」。
Part 2: 簡短問答 (Question-Response)
請仔細聆聽音檔問題，選出最適合的應答：
題目文本："What caused the data discrepancy between the two platforms?"
解析：問句詢問雙系統資料「不一致 (discrepancy)」的原因，正確解答為 (C)「在我們嘗試遷移 (migrate) 紀錄時發生了錯誤」。
Part 3: 簡短對話理解 (Short Conversation)
問題：What is the speaker mainly concerned about?
對話文本："Our primary database driver is not compatible with the updated operating system. We need to troubleshoot this immediately before deployment. If that fails, do we have an alternative contingency plan ready?"
解析：發言者提到驅動程式「不相容 (not compatible)」，需要進行「排除故障 (troubleshoot)」，並詢問是否有「應急備案 (contingency plan)」，故答案為 (B)。
Part 3: 簡短對話理解 (Short Conversation)
問題：What will the team do next?
對話文本："The engineering lead verified that the new pipeline operates in full compliance with the security specifications. We are ready to implement the update and reconcile all discrepancies."
解析：文本指出準備好「實施 (implement) 更新」並「消除核對所有不一致 (reconcile discrepancies)」，同義改寫為選項 (A) Deploy the update and align data records。
