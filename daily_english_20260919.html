Compatible adj.
/kəmˈpæt.ə.bəl/
相容的、可共存的、相配的
🔊 自然發音拆解
com-pat-i-ble: com (/kəm/) + pat (/pæt/) + i (/ə/) + ble (/bəl/)。
🧬 字根字首與來源
  • 字源：拉丁語 compati（共同承受）。
  • 構詞：com-（共同）+ pati-（承受）+ -ible（能夠...的）。
  • 家族字：Compatibility (n. 相容性), Incompatible (adj. 不相容的)。
🎯 TOEIC 700+ 聽讀核心考點
  • 🎧 聽力陷阱：字首 com- 弱化為 /kəm/，重音在第二音節 /pæt/。常考在 Part 3 辦公室採購軟硬體對話，例如抱怨新鍵盤或軟體與舊電腦不合。
  • 📖 閱讀必考搭配詞：be compatible with...（與…相容）。Part 5 最常出介系詞克漏字，四選一直接考你填 with。名詞型態 compatibility issues（相容性問題）也是閱讀高頻詞。
💼 PM 實戰例句與情境
"We must verify whether the new database driver is compatible with the existing operating system."
「我們必須驗證新的資料庫驅動程式是否與現有的作業系統相容。」
Migrate v.
/ˈmaɪ.ɡreɪt/
遷移、系統/資料搬遷轉移
🔊 自然發音拆解
mi-grate: mi (/maɪ/) + grate (/ɡreɪt/)。
🧬 字根字首與來源
  • 字源：拉丁語 migrare（搬遷、遷徙）。
  • 構詞：migr-（移動/流動）+ -ate（動詞字尾）。
  • 家族字：Migration (n. 遷移/移轉作業), Migratory (adj. 遷徙的)。
🎯 TOEIC 700+ 聽讀核心考點
  • 🎧 聽力陷阱：英式發音重音常落在第二音節 /maɪˈɡreɪt/，美式發音重音則在第一音節 /ˈmaɪ.ɡreɪt/。Part 4 企業內訓廣播中常出現。
  • 📖 閱讀必考搭配詞：migrate to [the cloud / a new platform]（遷移至雲端／新平台）。在 Part 7 的系統維護通知信中，migration period（系統移轉過渡期）通常會伴隨暫停服務（scheduled downtime）的考點。
💼 PM 實戰例句與情境
"The project timeline requires us to migrate five thousand customer records to the cloud repository by Friday."
「專案時程要求我們在週五前將五千筆客戶紀錄遷移至雲端儲存庫。」
Contingency n.
/kənˈtɪn.dʒən.si/
意外事故、緊急情況、備案措施
🔊 自然發音拆解
con-tin-gen-cy: con (/kən/) + tin (/tɪn/) + gen (/dʒən/) + cy (/si/)。
🧬 字根字首與來源
  • 字源：拉丁語 contingere（接觸、偶發事件）。
  • 構詞：con-（共同）+ ting-（觸及）+ -ency（名詞字尾）。
  • 家族字：Contingent (adj. 視情況而定的)。
🎯 TOEIC 700+ 聽讀核心考點
  • 🎧 聽力陷阱：第三音節 /dʒən/ 發軟音 g（像 jam 的開頭），不可發成硬音 /ɡ/。音節長度較多，需要留意快速語速下的重音節 /tɪn/。
  • 📖 閱讀必考搭配詞：90% 以上固定考片語 contingency plan（應變備案/緊急方案）或 contingency fund（緊急備用金）。在 Part 7 專案延宕或天候惡劣的商業對話中，是商務風險管理的典型得分詞。
💼 PM 實戰例句與情境
"As a risk management measure, the PM prepared a contingency plan in case the API connection fails."
「作為風險管理措施，專案經理準備了應急備案，以防 API 連線失敗。」

🎯 整合複習句型 (Synthesis Pattern)

"Before we migrate the database, we must ensure every module is compatible and have a solid contingency plan."
（在我們遷移資料庫之前，必須確保每個模組均能相容，並備妥完善的緊急應變方案。）
